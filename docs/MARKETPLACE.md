# Penombre

Low-glare themes for VS Code, built from GitHub's colors.

- **Penombre Ardoise**: dark, on slate
- **Penombre Papier**: light, on paper

Pick one in **Preferences: Color Theme**.

Color goes where you need to look: errors are red, warnings yellow, additions green, focus blue.
Plain code stays near-gray, and contrast is softer than GitHub's: about 10:1 for body text instead
of 16:1.

Source and issues: [github.com/bienbiendev/penombre](https://github.com/bienbiendev/penombre)
